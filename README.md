## 🚀 Overview

This repository contains the source code for my personal portfolio web application (`portfolio-martin-ordovas`). As a DAM (Desarrollo de Aplicaciones Multiplataforma) student and enthusiastic developer from Zaragoza, Spain, I built this portfolio to highlight my expertise across various technologies, programming languages, and operating systems.

The interface combines a sleek **glassmorphism** design with a **retro terminal aesthetic**, featuring dynamic particle animations and a fluid user experience.

---

## ✨ Key Features

- **Standalone Angular Architecture:** Built using Angular 22 with modern standalone components and reactive programming.
- **Tailwind CSS Styling:** Modern, utility-first styling with custom glassmorphic components and responsive layouts.
- **Interactive Canvas Engine:** Custom HTML5 Canvas particle/starfield background for an immersive visual experience.
- **Smooth Navigation:** Seamless scroll navigation and section transitions across desktop and mobile devices.
- **Structured Sections:**
  - **Home (Hero):** Introduction, professional title, and quick call-to-actions.
  - **About Me:** Personal bio, background, location (Zaragoza, Spain), and current status.
  - **Projects Showcase:** Detailed cards for key projects with GitHub and live demo links.
  - **Skills & Technologies:** Visual skill bars reflecting proficiency in Java, SQL, C#, Web Development, and Linux Administration.
  - **Contact:** Direct links to GitHub, LinkedIn, and email.

## 🛠️ Tech Stack
